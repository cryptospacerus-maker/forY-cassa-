## Проверка расчётов

- Исходный файл содержит ровно три обращения: R01 — доставка, R02 — возврат, R03 — доставка.
- «Доставка»: R01 + R03 = 2 обращения; 2 / 3 × 100 = 66,7% после округления.
- «Возврат»: R02 = 1 обращение; 1 / 3 × 100 = 33,3% после округления.
- Контроль сумм: 2 + 1 = 3 обращения; 66,7% + 33,3% = 100,0%. Каждое обращение учтено ровно один раз.
