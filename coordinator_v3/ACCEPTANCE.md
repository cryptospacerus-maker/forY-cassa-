# Матрица живой приёмки V3

Этапы после согласования архитектуры и проверки режима тарификации. Начальный PoC — максимум два вызова, по одному созданию и resume. Следующие живые вызовы относятся к отдельной эксплуатационной приёмке. Деградацию и гонки воспроизводим сначала на имитаторе.

| № | Испытание | Критерий |
| --- | --- | --- |
| 1 | Один CLI | Владелец видит ChatGPT auth. Синтетический ответ проходит схему, resume сохраняет thread ID, Usage сверено. |
| 2 | Два исполнителя | Два разных зарегистрированных worker получают только закреплённые роли. Недоступность одного не меняет маршрут. |
| 3 | Три аккаунта | Каждый подтверждает собственную авторизацию локально. Координатор видит три worker ID и не получает их авторизации. |
| 4 | Четыре агента | В журнале четыре роли, у Игорька и Андрюхи разные ID и рабочие каталоги. |
| 5 | Получение задачи | Команда из GitHub принимается один раз. Повтор и сообщение вне allowlist не запускают сессию. |
| 6 | Игорёк | План сохраняет критерии фильтра, зависимости и границы файлов из #18. |
| 7 | Тёма и Ксю | Изменения только в store.py и client.js, соблюдены зависимости плана. |
| 8 | Андрюха | Python и Playwright подтверждают office/kitchen/outdoor и возврат к All на одном SHA. Тестовый MCP подтверждён по журналу при включённом профиле. |
| 9 | Возобновление | В сценарии исправления новый turn идёт в прежнюю сессию нужной роли, затем QA проверяет новый SHA. |
| 10 | Публикация | SHA ветки равен SHA QA. Один итог бота содержит инициатора, вердикт и ссылку. |
| 11 | Семён | Запуск под greatsoutherntrendkill, актор совпадает с итоговым упоминанием. |
| 12 | Толя | Отдельный запрос под tolyapolya2006-png, актор совпадает с итоговым упоминанием. |
| 13 | Перезапуск | Принятая работа восстанавливается без второго turn, выданный шаг с неизвестным исходом останавливается до сверки. |
| 14 | Квота | Воркер переходит в quota, новые шаги ждут. Инициатор получает статус. Смена аккаунта и автоматический повтор отсутствуют. |

Сохранить ссылки на GitHub Issues, SHA, вердикт и безопасную выжимку событий. Личные логи и цифры из Usage передавать команде только в согласованном объёме. После приёмки Толя проводит независимое ревью. Панель подключается после подтверждения цикла.
