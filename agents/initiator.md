# Инициатор координатора

Семён и Толя запускают координатора из своих сессий Codex с доступом к GitHub. GitHub определяет инициатора по автору dispatch. Права записи и список разрешённых логинов проверяются на сервере.

Готовая команда для чата Codex.

> Запусти Coordinator MVP для Issue #13 в cryptospacerus-maker/forY-cassa- в режиме dry-run с ключом pilot-check-1. Воспользуйся моим текущим GitHub-аккаунтом, покажи его логин и ссылку на запуск. При повторе используй тот же ключ.

Codex должен проверить `gh api user --jq .login` и выполнить следующий вызов из сессии с авторизованным `gh`.

```sh
gh workflow run coordinator.yml -R cryptospacerus-maker/forY-cassa- \
  --ref main -f issue=13 -f request=pilot-check-1 -f mode=dry-run
```

Подтвердите, что ссылка ведёт к запуску нужного логина, номера Issue и ключа. Для поиска используйте `gh run list --workflow coordinator.yml --event workflow_dispatch --branch main --user <логин>` и заголовок запуска. При временной ошибке проверяйте существующий запуск по этому же ключу.

Для минимальной платной приёмки после согласования укажите `mode=demo` и новый ключ. Обычная задача запускается той же командой с `mode=task`; разрешённые возможности V2 применяются из настроек репозитория. [Единая инструкция](../coordinator/README.md) Ожидайте итог в Issue с упоминанием вашего логина. Другой участник может использовать тот же ключ в своей сессии. Платный запрос после аварии без завершённого состояния требует отдельного решения и нового ключа. API-ключ хранится в настройках репозитория GitHub.
