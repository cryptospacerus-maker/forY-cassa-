# Подготовка к хакатону ЮКассы

Семён и Толя настраивают совместную разработку в 3–4 сессиях ChatGPT или Codex. Тоня готовит презентацию и запись работы агента в бизнесе.

## Ближайший результат

Проверить на двух параллельных задачах, что сессия B учитывает обновление сессии A при следующем запросе, получив детали из GitHub.

19 ноября 2026 года сессии A и B подтвердили доступ в [Issue №1](https://github.com/cryptospacerus-maker/forY-cassa-/issues/1). По ответу, переданному Семёном, чат Толи верно определил цель, источник задач и порядок передачи работы.

## План репетиции

Разделить небольшой сценарий на задачи, выполнить их параллельно, изменить одно общее требование и передать незавершённую задачу другой сессии. Затем собрать тестового ИИ-агента за день и зафиксировать время, повторные попытки и доступные данные о расходах.

## Где искать актуальную информацию

Общие решения записываем здесь. Исполнитель, статус, зависимости и результат конкретной задачи находятся в GitHub Issues. Пример с обращениями магазина — возможный сценарий репетиции. Бизнес-кейс команда выбирает отдельно.

## Требование к сводке обращений (задача № 3)

Для каждой темы укажите долю обращений этой темы среди всех обращений в процентах, округлённую до одного знака после запятой.

## Приём кейса и наблюдение за работой

Координатор ведёт единственную главную карточку каждого кейса. После получения задания Семён или Толя добавляет сюда ссылку на неё. Карточка хранит версии и первоисточники. Решения команды, меняющие общий план, фиксируем здесь со ссылкой на версию. Исполнители ведут задачи по шаблону «Задача агента». Панель dashboard/index.html читает карточки раз в две минуты. Открой файл в браузере для публичного репозитория. Для закрытого репозитория запусти python3 dashboard/serve.py из checkout с авторизованным GitHub CLI и открой напечатанный локальный адрес.
