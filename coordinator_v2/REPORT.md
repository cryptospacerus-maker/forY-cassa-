# Coordinator V2. Архитектура и испытания

Ветка создана от `bf23f860c9c3c435a3867b5317468eecae620e1c` из PR #14. V2 добавляет собственные CLI, конфигурацию, состояние результатов и CI workflow. Код MVP и оба его workflow в diff V2 не входят.

## Архитектура

| Возможность | Реализация |
| --- | --- |
| Исполнение предложения | Агент возвращает только шаги из доверенного списка проверок и полное содержимое выделенных файлов. Координатор валидирует пути и создаёт временный Git-коммит для проверки. Две независимые роли используют отдельные рабочие снимки. |
| Песочница | Зафиксированный образ Playwright, непривилегированный UID, read-only root, сброс capabilities, no-new-privileges, лимиты CPU, памяти, процессов, времени и вывода. Docker запускает проверку без внешней сети и без Docker socket. Разрешены два read-only снимка Git, один с кандидатом и один с проверками из base. Рабочая копия и её Git-конфигурация в контейнер не монтируются. |
| Независимый QA | Проверки Андрюхи запускаются на одном точном SHA. Python-проверка выполняет код приложения отдельным процессом. Playwright поднимает временный локальный HTTP-сервер, открывает чистый профиль Chromium и пропускает запросы только на адрес стенда. После исправления обе проверки повторяются на новом SHA. |
| MCP | Фиксированный дочерний stdio-провайдер с синтетическими данными и протоколом MCP `2025-11-25`. Шлюз выполняет handshake, проверяет роль, инструмент, аргументы и структуру ответа. Кэш используется после проверки прав. Тестовый провайдер предоставляет только чтение. |
| Контекст и бюджет | Планировщик видит короткие описания и список до 40 путей. Исполнитель получает выделенные файлы и фрагменты результата предшественников. Изменение требований блокирует следующую стадию и выдачу кандидата. При дефекте повторяются ответственные роли и их зависимые задачи. Формальная QA-сессия не вызывается, когда автоматическая проверка уже вернула дефект. Один цикл исправления, две параллельные роли и до восьми сессий. В локальном режиме Codex используется ограничитель запросов и токенов MVP. |
| Журнал | JSONL фиксирует план, волны, передачу, обращения к MCP, QA, исправление и итог. Доказательство проверки включает SHA, ID команды, статус, код выхода, длину и хеш усечённого вывода. Короткие диагностические строки передаются только роли при доработке. |

Chromium запускается с изоляцией контейнера. Собственная песочница Chromium отключена для совместимости с настройками Docker CI. Для обработки намеренно вредоносных приложений нужен отдельный усиленный раннер с изоляцией на уровне VM. Текущий Playwright-сценарий работает с синтетическим каталогом. Сторонние MCP-серверы, реальные платежи и платные запуски Codex в испытаниях не участвовали.

## Подтверждённые сценарии

- Две независимые роли работают параллельно. В зависимом сценарии интерфейс получает сводку предыдущей роли и ограниченный фрагмент результата. Пересечение путей, цикл и команда вне полномочий блокируются.
- Изменение требований после начала работы прерывает выполнение до QA. При тайм-ауте проверка фиксирует ошибку и удаляет контейнер.
- В сквозном сценарии тест неизвестной категории отклоняет первый Git-коммит. Интерфейсный сценарий проходит. Координатор возвращает доработку только Тёме и запускает обе независимые проверки на новом SHA.
- Синтетический MCP-провайдер получает один фактический запрос благодаря кэшу. Запись, посторонняя роль, чужая категория и дополнительные аргументы отклоняются до транспорта.
- Артефакт Git pack восстанавливает точный проверенный SHA в новом репозитории с базовой версией. Журнал пригоден для чтения без доступа к содержимому запросов.

Локальный быстрый набор проверяет механику координации и настоящий stdio-транспорт MCP. Сквозной CI дополнительно использует Docker и Chromium. Генерация ответов ролей в проверках сценарная. [Инструкция по запуску](README.md)
